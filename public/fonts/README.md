Original files from https://github.com/google/fonts (ofl/barlow, ofl/barlowcondensed, ofl/anton, ofl/bebasneue, ofl/librecaslontext, ofl/spacemono). License texts are in licenses/. LibreCaslonText.ttf is the original LibreCaslonText[wght].ttf variable font, renamed without modifying its contents. These same TTF files are used by captionFonts.css and the FFmpeg ass fontsdir option. No font download is needed at runtime.

The editor additionally bundles Montserrat, Inter, Archivo Black, Playfair Display, Cinzel, Syne, Poppins, Oswald, and JetBrains Mono from their corresponding google/fonts ofl directories. Additional variable families are instantiated at weight 700 with FontTools (other axes use the defaults), so browser and libass select identical bold outlines. Poppins uses Bold. Each family includes its original OFL license in licenses/. The picker offers these 15 redistributable families. Older Impact, Arial Black, and Georgia settings map to Anton, Archivo Black, and Libre Caslon Text respectively.
